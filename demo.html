Embed Code for Your Website

Copy the code below and paste it into your website's footer where you want the Instagram widget to appear.

Option 1: Basic Iframe Embed (Recommended)

Simple and straightforward. Just paste this code into your HTML:

<iframe src="https://your-deployed-url.com" width="100%" height="800" frameborder="0" scrolling="no" title="Straw Hut Media Instagram Feed"> </iframe>

Option 2: Responsive Iframe Embed

This version automatically adjusts height based on screen size:

<div style="position: relative; width: 100%; padding-bottom: 60%; overflow: hidden;"> <iframe src="https://your-deployed-url.com" style="position: absolute; top: 0; left: 0; width: 100%; height: 100%; border: 0;" title="Straw Hut Media Instagram Feed"> </iframe> </div>

Deployment Instructions

Before embedding, you need to deploy this widget to a hosting service. Here are the steps:

  • Step 1: Set up your Instagram API access token (see README.md)
  • Step 2: Deploy to a hosting service (Vercel, Heroku, Railway, etc.)
  • Step 3: Replace https://your-deployed-url.com in the embed code with your actual deployment URL
  • Step 4: Paste the embed code into your website's footer

Quick Deploy Commands:

# Deploy to Vercel npm install -g vercel vercel # Deploy to Heroku heroku create strawhut-instagram-widget git push heroku main heroku config:set INSTAGRAM_ACCESS_TOKEN=your_token_here # Deploy to Railway npm install -g @railway/cli railway up
